# SHACT - Searching Hacktons and Create Teams

**SHACT(Searching Hacktons and Create Teams)** - это проект, формата Web-сервиса, обеспечивающее парсинг Хакатонов и формирование командных состав людей для участия в них. Web-приложение **«SHACT»** - реализует функционал сбора информации о Хакатонах проходящих на территории РФ с последующей возможностью создания произвольных команд для участия пользователя. Каждый зарегистрированный пользователь платформы имеет возможность создать команду или же присойдинится к существующей команде при предварительной связе с лидером команды, контакты(VK,TG,DISCORD) которого указаны в карте команды.

## Технологический стэк разработки проекта

### Frontend
- [ ] **HTML** - стандартизированный язык гипертекстовой разметки документов для просмотра веб-страниц в браузере.
- [ ] **CSS** - Язык описания дизайна Web-сервиса
- [ ] **React** - Библиотека исполнения JS + **JavaScript**
- [ ] **SASS** - Наиболее развитое и стабильное расширение CSS профессионального уровня.
- [ ] **TypeScript** - Язык программиирования позиционируется как средство разработки веб-приложений, расширяющее возможности JavaScript.
### Backend
- [ ] **С#** - Объектно-ориентированный язык программирования общего назначения.
- [ ] **MongoDB** - Документоориентированная система управления базами данных, не требующая описания схемы таблиц.
